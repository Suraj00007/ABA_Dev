    Rollback

    How to undo

    To undoHow
    Reports, dashboards, foldersDelete them from the Reports and Dashboards tabs. Delete the dashboards first, then the reports, then the empty folders.
    Home pageSetup → Lightning App Builder → ABA Sales Home Page → Activation → remove the Sales app assignment. Then the page can be deleted.
    Fields, validation rule, flowDeactivate the flow and the rule. Remove the fields from reports first, then delete the fields in Object Manager. Deleted fields stay restorable for 15 days.
    Picklist valuesReactivate the old values in Object Manager. Deactivate the new ones only after records using them are updated.
    Sample dataDelete the 52 ABA opportunities and 12 accounts listed above (IDs shown). Restore the 31 old opportunities from the backup CSV with Data Loader. Restored records get new IDs.
    UsersUsers can't be deleted in Salesforce. Deactivate Venkatesh Rethinasamy and Mohammed Alburayh to free the licences.
    Audit-field settingSetup → User Interface → untick “Enable ‘Set Audit Fields upon Record Creation’…”, and remove the ABA Historical Data Load permission set.
